# Organization logo sources

These marks identify the organizations in Donald Loveland's career history.
They are bundled locally from publicly available downloads. The names and marks
belong to their respective organizations; no endorsement is implied.

| Asset | Source | Preparation |
| --- | --- | --- |
| `snap.svg` | [Snap Research](https://research.snap.com/), [original SVG](https://research.snap.com/assets/img/snap-logo.svg) | Kept the original black-and-white ghost paths used by Snap Research; removed the yellow background rectangle. |
| `michigan.svg` | [University of Michigan wordmark on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:University_of_Michigan_logo.svg), [original SVG](https://upload.wikimedia.org/wikipedia/commons/c/c1/University_of_Michigan_logo.svg) | Extracted the existing maize Block M path and its transforms. Commons identifies the simple logo as public domain. |
| `amazon.svg` | [Amazon in Bootstrap Icons](https://icons.getbootstrap.com/icons/amazon/), [v1.13.1 SVG](https://github.com/twbs/icons/blob/v1.13.1/icons/amazon.svg) | Used the monochrome Amazon icon. MIT license reproduced in `BOOTSTRAP-LICENSE.txt`. |
| `mit-lincoln.svg` | [MIT Lincoln Laboratory logo](https://www.ll.mit.edu/about/history/lincoln-laboratory-logo), [official standalone SVG](https://www.ll.mit.edu/themes/mitll_theme/assets/logos/mitll-logo.svg) | Used the official standalone mark with black fill for the light page background. Paths are unchanged. |
| `llnl.svg` | [LLNL logo on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Lawrence_Livermore_National_Laboratory_logo.svg), [original SVG](https://upload.wikimedia.org/wikipedia/commons/f/fd/Lawrence_Livermore_National_Laboratory_logo.svg) | Extracted the blue symbol; removed the wordmark and white background rectangle. Commons marks the source as public domain. |

SVG viewports fit the artwork with equal proportional padding. CSS provides the
same box for every icon within each timeline: 28 × 28px on the homepage and
24 × 24px on the experience page. Each logo's aspect ratio is preserved. No logo
has a background panel, border, or crop mask. Retrieved November 9, 2026.
